# 레시피 조리단계 사진 넣는 법

큐레이션 레시피 8개(마이페이지 칼로리별 예시식단에도 쓰이는 것들)는 "만드는 방법" 각 단계마다
사진을 보여줄 수 있게 코드가 이미 준비되어 있어요. 아래 경로에 **정확히 이 파일명**으로
jpg를 넣기만 하면, 앱을 새로고침했을 때 자동으로 나타납니다. 안 넣은 단계는 그냥 사진 없이
번호+텍스트만 보여서 앱이 깨지지 않아요.

- 폴더: `frontend/public/images/recipes/<레시피 slug>/`
- 파일명: `step-1.jpg`, `step-2.jpg`, `step-3.jpg`, `step-4.jpg` (레시피마다 정확히 4단계)
- 형식: `.jpg` 고정 (다른 확장자로 저장하면 안 뜹니다)
- 비율: 4:3 권장 (가로/세로가 안 맞으면 가운데 기준으로 잘려서 표시돼요)

레퍼런스 카드뉴스(`레시피/레시피 사진/`)처럼 **따뜻한 베이지/크림 톤, 자연광, 탑뷰 또는
45도 앵글 정물 사진** 느낌으로 통일하면 앱 안에서 예뻐 보여요.
